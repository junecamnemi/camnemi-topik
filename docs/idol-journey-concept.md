# Glowsis AI TOPIK — 아이돌 성장 여정 (기획 초안)

## 진행 규칙 (확정)
- 전체 6레벨 × 각 레벨 안 10단계 = 최대 60단계
- 레벨 진입 조건: 그 레벨에서 **공부 100시간 + 문제 100문제 + 정답률 70%**
  (Lv2 진입 = 누적 100시간·100문제, Lv3 = 200시간·200문제, … Lv6 = 500시간·500문제)
- 레벨 안 10단계 = 그 레벨의 100시간을 10구간(10시간/단계)으로 조금씩 성장

## 레벨 안 10단계 성장 (예: Lv2 데뷔)
각 10시간 마다 1단계 — 연습생 → 트레이닝 → 안무/보컬 → 리허설 → 무대.

(모든 60단계 이름은 확정 후 생성)
