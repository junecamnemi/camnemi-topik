## Level 3 필요 조건 (TOPIK II)
- **합격선**: 120/300점 (읽기·듣기 각 100점 + 쓰기 100점)
- 대학 지원 핵심: **3급 이상 요구하는 대학이 대부분**
- 시험 구조: 듣기 50문항(60분) + 쓰기 4문항(50분) + 읽기 50문항(70분)

---

## 콘텐츠 확장 로드맵

### 🎯 1단계 — 문법 (TOPIK II 필수 150)
- [ ] 150개 문법을 **레벨별(3급/4급/5급/6급)** 분류
- [ ] 각 문법에 **원본 예문 2~3개** 작성 (저작권 안전)
- [ ] 문법 카드 데이터(`data/topik2-grammar.js`)로 앱에 통합
- [ ] 레벨 테스트에 3급 문법 문항 추가

### 📚 2단계 — 어휘 (6000 words)
- [ ] TOPIK II 필수 어휘를 **급수별(3급~6급)** 정리
- [ ] 플래시카드 모드 구현 (앱)
- [ ] 문장 예문 + 음성 지원

### ✍️ 3단계 — 문제은행 전환 (TOPIK II)
- [ ] 기존 TOPIK I 문제는 "기초 복습" 섹션으로 유지
- [ ] **TOPIK II 읽기 50문항 규모** 원본 문제 생성
  - 유형: 빈칸(문법/어휘), 내용 일치, 중심 내용, 순서 배열, 문장 위치, 긴 지문
- [ ] **듣기 50문항 규모** 원본 문제 + TTS 음성
- [ ] **쓰기 문항** (짧은 에세이/완성) — 체크리스트 평가

### 🎧 4단계 — 기출·모의고사
- [ ] TOPIK II 기출 회차 확보 (공식/무료 소스)
- [ ] 3급 목표 모의고사 (실제 시간 제한)
- [ ] 점수 예측 → "현재 레벨" 표시

### 🌍 5단계 — 다국어
- [ ] UI 영어 (현재) → 크메르어/베트남어/인도네시아어 등
- [ ] 설명 언어 선택 기능

```

```

3. **쓰기 연습** (Level 3에서 쓰기 100점 중 상당 비중)
