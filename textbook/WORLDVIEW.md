# 꿈별 (KKUMBYEOL) — 4인조 걸그룹 세계관 콘셉트

## 그룹 컨셉
- **그룹명:** 꿈별 (Kkumbyeol) — "꿈(Dream) + 별(Star)" = 꿈나라의 별
- **컨셉:** 리센느(RESCENE)풍 몽환·동화 감성 — 동화책에서 현실로 떨어진 요정 4명
- **스토리:** 꿈나라(Dreamworld)에서 길을 잃고 현실 세계에 떨어진 요정들.
  한국어를 배워 "마법의 문"을 여는 비밀 주문을 외우면 꿈나라로 돌아갈 수 있다!
  → 한국어 공부 = 세계관 진행 (각 과를 끝내면 마법의 문이 조금씩 열림)
- **멤버 이름 = 한국어 단어** → 한국어 학습과 자연스럽게 연결

## 멤버 콘셉트 (서로 완전히 다른 비주얼/성격)

### 별이 (Byeori) — ⭐ 별 (star)
- **포지션:** 리더 · 메인보컬
- **비주얼:** 따뜻한 갈색 보브컷(단발) + 별 모양 머리핀, 호박색(갈색) 눈
- **성격:** 책임감 강하고 다정한 언니. 팀을 이끌며 한국어를 제일 열심히 공부함
- **상징어:** 따뜻함, 리더십, 별빛
- **컬러:** 앰버/골드

### 달이 (Dari) — 🌙 달 (moon)
- **포지션:** 보컬
- **비주얼:** 긴 검은 생머리 + 초승달 머리핀, 푸른빛 검은 눈
- **성격:** 차분하고 시크한 분위기. 말수 적지만 시 한 줄처럼 깊은 감성
- **상징어:** 청순, 신비, 달빛
- **컬러:** 블루/실버

### 소리 (Sori) — 🎵 소리 (sound)
- **포지션:** 메인댄서 · 랩
- **비주얼:** 밝은 금발 트윈테일(양갈래) + 음표 머리핀, 주황빛 눈
- **성격:** 에너지 넘치고 장난꾸러기. 춤추는 걸 제일 좋아함
- **상징어:** 활기, 리듬, 노래
- **컬러:** 옐로우/피치

### 꽃이 (Kkochi) — 🌸 꽃 (flower)
- **포지션:** 막내 · 비주얼
- **비주얼:** 핑크 숏컷(단발) + 꽃 머리핀, 라벤더(보라) 눈
- **성격:** 순수하고 몽환적인 요정. 자꾸 꿈나라로 돌아가고 싶어함
- **상징어:** 순수, 동화, 꽃잎
- **컬러:** 핑크/라벤더

## 스토리 진행 (8과 = 8개의 꿈 조각)
- 각 과를 끝내면 '꿈의 조각' 1개를 모음
- 8개를 다 모으면 마법의 문이 열림 → 1B로 이어짐
- 각 과 시작에 멤버들의 꿈나라 이야기 (일러스트와 함께)
