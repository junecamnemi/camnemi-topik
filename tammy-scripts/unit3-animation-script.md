# 파트 A — 기본 편 (약 10분)

## A1. 오프닝 (0:00–0:40)
🎬 Glowsis 멤버들(아란·채아·다희·로이)이 응원봉·앨범·포토카드를 앞에 두고 신기해함.
🎙 "오늘은 '이거 뭐예요?' What is this? 를 배워요."
🎙 "근데 잠깐 — 영어에 'that'이 하나인데, 한국어엔 왜 '그'와 '저' 둘이 있을까요?"
💬 다희: "이거 뭐예요? 신기해요!"
🎙 "오늘 그 비밀을 풀어볼게요!"

## A2. 이/그/저 개념 (0:40–1:50)
🎬 세 물건: 손 옆 응원봉(이), 상대 옆 포토카드(그), 멀리 앨범(저).
🎙 "이 = this, 나에게 가장 가까운 것."
🎙 "그 = that, 듣는 사람에게 가까운 것."
🎙 "저 = that, 나와 너 둘 다에게 먼 것."
💬 아란: "이거는 응원봉이에요!" (손 옆)
💬 채아: "그거는 포토카드예요." (상대 옆)
💬 로이: "저거는 앨범이에요." (멀리)
🎙 "이 → 그 → 저, 거리 순서예요. 그림으로 기억하세요!"

## A3. 이것/그것/저것 + 받침 규칙 (1:50–3:10)
🎬 "것 = thing" 카드.
🎙 "이 + 것 = 이것. 그 + 것 = 그것. 저 + 것 = 저것."
🎙 "그리고 '무엇 = what', 줄여서 '뭐'."
🎬 이것/그것/저것 맨 끝 ㅅ 받침 강조.
🎙 "주의! 이것·그것·저것 은 끝에 ㅅ 받침이 있어요."
🎙 "그래서 주제 조사는 '은'을 써요. 이것은, 그것은, 저것은."
🎙 "이거 뭐예요? → 이거 는 뭐예요? 에서 주제 조사가 빠진 거예요. 실제 대화에선 그냥 이렇게 줄여요."

## A4. 대화 장면 (3:10–5:00)
🎬 굿즈 판매대 (Glowsis 부스).
💬 로이: "이거 뭐예요? What is this?"
💬 아란: "이거는 응원봉이에요. 팬들이 콘서트에서 써요. This is a light stick."
💬 다희: "그거는 뭐예요?"
💬 채아: "그거는 앨범이에요."
💬 로이: "저거는? That one over there?"
💬 아란: "저거는 포토카드예요."
🎙 "가게에서 물건 이름을 물을 때: 이거 뭐예요? 그거 뭐예요? 저거 뭐예요?"

## A5. 어휘 — 보케블러리 (5:00–7:00)
🎬 굿즈 카테고리. 단어 카드 + 🔊 발음.
🎙 "오늘의 어휘예요. 따라 말해보세요!"
- **응원봉** eung-won-bong — light stick
- **앨범** ae-beom — album
- **포토카드** po-to-ka-deu — photocard
- **티셔츠** ti-syeo-cheu — T-shirt
🎬 폰/음악 카테고리.
- **휴대폰** hyu-dae-pon — cell phone
- **이어폰** i-eo-pon — earphones
- **사진** sa-jin — photo
🎙 "잘 쓰는 말도 같이 배워요."
💬 "응원봉을 들어요. — Hold up the light stick."
💬 "앨범을 사요. — I buy an album."
💬 "포토카드를 모아요. — I collect photocards."
💬 "휴대폰이 없어요. — I don't have a phone."

## A6. 있어요 / 없어요 (7:00–8:20)
🎬 가방 속 책(있음) / 빈 가방(없음).
🎙 "있어요 = 있다, 있어요. 없어요 = 없다, 없어요."
🎙 "무엇이 있는지 말할 때: [물건]이 있어요 / 없어요."
💬 "포토카드가 있어요. There is a photocard."
💬 "시간이 없어요. I don't have time."
🎬 질문 대화.
💬 손님: "포토카드 있어요?" (Is there a photocard?)
💬 점원: "네, 있어요. / 아니요, 없어요."
🎙 "존재를 물을 때 '이 있어요?' 하고, 있으면 '네, 있어요', 없으면 '아니요, 없어요'."

## A7. 주세요 (8:20–9:30)
🎬 굿즈 판매대에서 사기.
🎙 "원하는 걸 부탁할 때: [물건] 주세요 — Please give me ~."
💬 "포토카드 주세요. Please give me the photocard."
💬 "물 주세요. Please give me water."
💬 로이: "저거 주세요!" (멀리 있는 앨범) → 저 + 주세요
🎙 "멀리 있는 걸 원하면 '저거 주세요'! 이/그/저 + 주세요 조합이에요."
🎬 공손 표현 (Tammy식).
🎙 "더 공손하게: '-아/어 주세요.' 요 form에서 요를 떼고 주세요를 붙여요."
💬 "사인해 주세요. Please give me an autograph."
💬 "빌려 주세요. Please lend me it."

## A8. 마무리 + 미리보기 (9:30–10:00)
🎬 지금 배운 문장 4개 리스트.
🎙 "오늘 배운 것: 이/그/저 → 이것/그것/저것, 있어요/없어요, 주세요."
🎙 "이제 굿즈 부스에서 직접 물건을 사고 물어볼 수 있어요!"
🎙 "다음 편에선 문제로 복습해요. 한국어 화이팅! 🎉"

# 파트 B — 심화 문제풀이 편 (별도, +10분)

> 기본 편 복습 + TOPIK 유형 문제. 문제마다 [❓문제 → ⏸️ 잠깐 생각 → ✅정답+설명].

## B1. 지시대명사 문제 (0:00–2:30)
❓1. 사진이 내 손에 있을 때. "이거 뭐예요?" (네) — 이
❓2. 사진이 상대 옆일 때 → "그거 뭐예요?" — 그
❓3. 공이 멀리 있을 때 → "저거 뭐예요?" — 저
✅ 설명: 이=나 가까이, 그=너 가까이, 저=둘 다 멀리.

## B2. 받침 규칙 문제 (2:30–4:00)
❓4. 이것 ___ 필통이에요. → (은)
❓5. 저것 ___ 물이에요. → (은)  [저것 끝 ㅅ 받침]
✅ 설명: 이것/그것/저것 ㅅ 받침 → 은.

## B3. 있어요/없어요 문제 (4:00–6:00)
❓6. [그림: 기타 1개] → "기타가 있어요." (✅)
❓7. "시간이 없어요." 뜻? → "I don't have time / There's no time." (✅)
❓8. [가방에 책] "가방에 책이 있어요?" → "네, 있어요."

## B4. 주세요 문제 (6:00–8:00)
❓9. 굿즈 부스에서 앨범 사기 → "앨범 주세요." (✅)
❓10. 멀리 있는 것 원할 때 → "저거 주세요." (✅)
❓11. 공손히 부탁 → "사인해 주세요." (✅)

## B5. 종합 복습 + 랜덤 (8:00–10:00)
🎙 "지금까지 나온 문장 중 맞는 걸 고르세요!"
❓12. 주세요 vs 있어요 구분: "응원봉 주세요." vs "응원봉이 있어요." → 상황에 맞는 것
❓13. 이/그/저 종합: 멀리 있는 축구공 → "저거는 공이에요." (✅)
🎬 성취 화면: ⭐ GLOW POINT 획득!
🎙 "다 풀었어요! 이제 굿즈 부스에서 자유롭게 사고 물어볼 수 있어요. 한국어 화이팅! 🎉"
