## 1) 이 / 그 / 저 — 지시대명사 (E10)

### Tammy의 핵심 설명 방식
> "왜 한국어에 'that'이 두 개 있죠?" → 거리(distance) 개념으로 접근

- **이** = "this" — **말하는 사람(나)에게 가장 가까운 것**
- **그** = "that" — **듣는 사람에게 가까운 것** (close to the listener)
- **저** = "that" — **나와 듣는 사람 둘 다에게 먼 것** (far from both)

**정리: 이(가장 가까움) → 그(조금 멀리) → 저(멀리)**

### 이것 / 그것 / 저것 — "thing" 붙이기
> 이것 = 이(this) + 것(thing)

- **이것** = this thing → "this"
- **그것** = that thing → "that"
- **저것** = that thing (over there) → "that"
- **무엇** = "what" — 흔히 줄여서 **뭐**
- **어느 것** = "which"

### 받침 규칙 (핵심 꿀팁)
> 이것/그것/저것 은 끝에 **ㅅ 받침**이 있으므로, 주제 조사 **은** 을 씁니다.
> → **이것은 / 그것은 / 저것은** (가 아닌 이것는)

### 대화 예시 (E10 — 필통 가게)
- 토미: **이것은 필통입니까?** (Is this a pencil case?)
- 점원: **아니요, 그것은 필통이 아닙니다. 안경케이스입니다.** (No, that's not a pencil case. It's a glasses case.)
- 토미: **저것은 무엇입니까? 필통이 아닙니까?** (What is that? Isn't it a pencil case?)
- 점원: **네. 맞습니다. 저것은 필통입니다.** (Yes, that's right. That's a pencil case.)

### Tammy의 문장 만들기 접근
> 좋습니다(prefer) 문형으로 받침 규칙 연습 — "저는 이 ○○이 좋습니다"
- **저는 이 선생님이 좋습니다** (선생님 받침 ㅁ → 이)
- **저는 이 한국드라마가 좋습니다** (드라마 무받침 → 가)
- **저는 이 노래가 좋습니다** (노래 무받침 → 가)

## 2) N 있어요 / 없어요 — 존재 구문

> Tammy 강좌에는 전용 강좌가 없지만, E27 대화에서 자연스럽게 등장:
> "혹시 **더 필요한 것 있으세요?**" (Is there anything else you need?)
> 교재 Unit 3에서는 "있어요 = 있다(to exist/have) / 없어요 = 없다(to not exist)"로 정리.

**보강 예문 (교재 기준)**
- 포토카드가 있어요. (There is a photocard.)
- 시간이 없어요. (I don't have time / There's no time.)
- 질문형: 포토카드 있어요? → 네, 있어요. / 아니요, 없어요.

## 3) N 주세요 — "주세요"로 부탁하기 (E27)

### Tammy의 핵심 설명 방식
> 두 가지 존칭 표현으로 접근: 부드럽게 **-아/어 주세요** / 더 공손하게 **-아/어 주시겠어요?**

- **-아/어 주세요** = "Please do something" (for me)
- **-아/어 주시겠어요?** = "Could you~?" (extra polite)

### 만드는 법 (Tammy의 공식)
> **요 form에서 요를 떼고 주세요를 붙인다.**

- 사인하다 → 사인해요 → **사인해 주세요** (Please give me an autograph)
- 빌려주다 → **빌려 주시겠어요?** / **빌려 주세요** (Please lend me a pen)
- 바꾸다 → 바꿔요 → **바꿔 주세요** (Please change it)

### Unit 3 교재 접목 (물건 주세요 — 굿즈 판매대)
> 교재는 **N 주세요 = "Please give me N"** 로 물건 사기/굿즈 부스에 활용
- **포토카드 주세요.** (Please give me the photocard.)
- **물 주세요.** (Please give me water.)
- **저거 주세요.** (Please give me that one over there → 저 + 주세요)

### E27 대화 예시 (펜 빌리기)
- 토미: **펜을 좀 빌려주시겠어요?** (Can you lend me a pen?)
- 상민: **네. 이거 쓰세요.** (Yes, please use this.)
- 토미: **그럼 수정테이프도 빌려주세요.** (Then please lend me the correction tape too.)
- 상민: **네. 여기요.** (Yes, here you go.)

### 보조 어휘 (E27 — 문구류)
- 펜 pen · 연필 pencil · 가위 scissors · 샤프 mechanical pencil · 수정테이프 correction tape

## Tammy 설명 방식의 공통 패턴 (애니메이션에 활용)

1. **질문으로 시작**: "왜 that이 두 개야?" → 호기심 유발
2. **거리/그림으로 개념화**: 이=나에게 가까움, 저=멀리 → 시각화
3. **받침 규칙을 반복 연습**: 좋습니다 문형으로 이/가 규칙 체화
4. **실생활 대화로 마무리**: 가게에서 물건 사기 → 바로 쓸 수 있게
5. **한국어 화이팅!** 긍정적 마무리
